# AkinLearning Science photo assets

The Science Exercises photo pack is stored locally so missions work offline. Each file is a reviewed 1024×768 JPEG with one dominant subject and no labels, arrows, or answer-revealing marks. The canonical metadata and SHA-256 values live in `src/data/subjects/sciencePhotoAssets.js`.

All source files were retrieved from Wikimedia Commons on 2026-09-07 under CC0 1.0 or public-domain status. The runtime files are crops/resizes of the source files; the source page and creator remain in the registry for audit and attribution.

The pack currently covers the plant-part photos (`plant-root`, `plant-stem`, `plant-leaf`, `plant-flower`, `plant-fruit`) and the Science-only animal overrides (`fish`, `duck`, `dolphin`, `whale`). The same canonical photo may be reviewed again in a later challenge, but a single challenge must never present the same asset ID, path, or hash twice.
